Which is the Latest ECMAScript?
ES9 (ECMAScript 2018) is the later version compared to ES6 (ECMAScript 2015).

ES9 was a smaller update compared to ES6 and focused mainly on improving the language's 
syntax and functionality with a few new features:
Asynchronous iteration (for-await-of loop)
Object Rest/Spread Properties
RegExp improvements (like s flag for dotall mode)
JSON improvements (e.g., JSON.stringify() improvements).

Why Use <script> at the End of <body>?
When you include a script at the bottom of the <body>, it ensures that:
The HTML content is already loaded before the script runs.
You avoid errors like document.getElementById(...) returning null, because the DOM elements now exist.
